# GitHub Submission Checklist

Before sharing the repository:

- [ ] Run `pip install -r backend/requirements.txt`
- [ ] Run `python backend/app.py`
- [ ] Open `http://127.0.0.1:5000`
- [ ] Test "Successful demo"
- [ ] Test "Re-planning demo"
- [ ] Click "Approve & Book"
- [ ] Click "View memory" and confirm the trip was stored
- [ ] Check that `README.md` is visible on GitHub
- [ ] Check `docs/architecture.md`
- [ ] Do not upload API keys or passwords
- [ ] Commit and push the complete repository
